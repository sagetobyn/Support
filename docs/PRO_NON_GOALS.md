# Pro Non-Goals

Pro deliberately does not build:

- Real automated courier action push.
- Full Shopify/WooCommerce production integration.
- Full Shiprocket/NimbusPost/Delhivery production integration.
- Real payment gateway integration.
- Real WhatsApp automation by default.
- ML risk model.
- Autonomous AI agents.
- Multi-brand portfolio.
- Managed ops team.
- Returns intelligence.
- Inventory optimization.
- Cashflow reconciliation.
- Full customer support inbox.
- Shipping label generation.
- Warehouse management.
- Marketplace or ERP.
- Advanced RBAC.

Pro includes CSV-first workflows, provider-ready messaging, policy recommendations, founder reports, integration scaffolding, mock connectors, import templates, webhook placeholders, local-only settings placeholders, and export files for ops teams.
