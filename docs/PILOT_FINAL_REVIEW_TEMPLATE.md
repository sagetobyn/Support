# Pilot Final Review Template

Use this at the end of a 14-day COD/RTO/NDR rescue pilot. The purpose is to make one clean decision: renew, narrow, or stop. Do not treat estimated savings as verified savings unless the seller has delivery, cancellation, finance, or courier proof.

## Decision Rule

- Renew only when the pilot produced a repeatable daily operating habit, estimated savings above the pilot fee, and at least one verified savings proof artifact.
- Narrow when the pilot produced useful estimated savings or action proof, but verification is missing or the cohort is too broad.
- Stop when data trust, action discipline, NDR rescue proof, or savings evidence is missing.

- Baseline came from seller summary numbers or anonymized CSV.
- Each estimated saving has a formula.
- Each verified saving has order outcome proof.
- Failures are included, not hidden.
- Next plan is one of renew, narrow, or stop.
