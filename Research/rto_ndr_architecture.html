05

AI Agent Architecture

All agents are recommendation agents in Phase 1 — humans approve actions. Automation comes in Phase 3+.

⚡ Rule-based engines first. LLM agents only where rules fail — NLP-heavy tasks like address parsing, intent classification, and insight generation.
🎯

Order Risk Agent

Scores COD orders 0–100 across 10 weighted signals. MVP is pure rules. Phase 4 adds ML trained on historical outcomes.

MVP · Rules First
🗺️

Address Quality Agent

Detects missing house numbers, bad pincodes, ambiguous localities. Uses regex rules + optional LLM for edge cases.

MVP · Regex + LLM
📋

NDR Reason Agent

Normalizes courier-specific reason strings ("Customer Not Available", "CNR", "CN", etc.) into 8 canonical categories.

MVP · LLM Classifier
💬

Customer Messaging Agent

Selects and personalizes WhatsApp template based on NDR reason, customer language preference, and order details.

MVP · Template Engine
🧠

Intent Detection Agent

Classifies free-text or button replies into 6 intents: confirm_delivery, change_address, reschedule, cancel, convert_prepaid, unknown.

MVP · LLM + Rules
🚚

Courier Action Agent

Given risk score + NDR reason + customer intent, recommends one of 7 actions: ship, hold, reattempt, update_address, call_customer, convert_prepaid, mark_rto.

MVP · Decision Tree
📊

Analytics Agent

Explains RTO trends in natural language: "RTO increased 4% this week — 70% from pincode 201301, likely due to courier change."

Phase 4 · LLM Insights
💰

Finance Agent

Calculates real-time ROI: money saved per order, cost per WhatsApp message, net savings after platform fee.

MVP · Calculation
🗓️

Ops Manager Agent

Creates a prioritized daily task list for the human operator: "12 NDRs need action today — 3 critical, 5 high risk."

Phase 3 · Automation
📈

Growth Agent

Suggests seller campaigns: COD→prepaid conversion offers, reorder reminders, delivery timing nudges based on order behavior.

Phase 4 · Strategic
